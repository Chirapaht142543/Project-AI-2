ตั้งค่าเชื่อมต่อระบบ

ระบบความปลอดภัยเซิร์ฟเวอร์เปิดใช้งานแล้ว (คีย์ได้รับการปกป้องสูงสุด)

ใช้คีย์ **Gemini** (สมัครฟรี) หรือคีย์ **OpenAI** (เสถียร/มีค่าใช้จ่าย)

URL ที่ได้จากการ Deploy Apps Script

สลับรุ่นเพื่อช่วยแก้ปัญหาเมื่อโควต้าโมเดลฟรีเต็ม

สถานะระบบ

Gemini API: ยังไม่ตั้งค่า
Google Sheet API: ยังไม่ตั้งค่า

ระบบผู้ดูแลระบบ

บัญชีของคุณได้รับสิทธิ์สูงสุด สามารถเข้าแผงจัดการหลังบ้านได้ครับ

จัดการระบบหลังบ้าน ⚙️

บอตแปลงภาพอัจฉริยะ (Vision OCR Sheet Bot)

ส่งข้อความหรือรูปภาพเพื่อแปลงข้อความและบันทึกสู่ Google Sheets ของคุณแบบเรียลไทม์

สวัสดีครับ! ยินดีต้อนรับสู่ **MT-TOPUP AI** 🤖✨

ผมช่วยคุณแปลงข้อความจากรูปภาพ เช่น ใบเสร็จ ใบส่งของ ป้ายข้อมูล หรือเอกสารต่าง ๆ จากนั้นจะส่งข้อมูลขึ้นสู่ **Google Sheets** ของคุณทันที!

กรุณากรอก **Gemini API Key** และ **Google Sheets Web App URL** ในแผงการตั้งค่าด้านซ้ายมือก่อนเริ่มต้นใช้งานนะครับ
